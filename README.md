## 🚀 Flagship Projects

### 🏛️ EasyArchitecture

> An AI-first architectural floor plan generation platform currently under development.

* **Current Status:** Work in progress — actively being designed and developed as a long-term architecture-tech project.
* **Core Idea:** A boundary-first floor plan tool where users define an irregular building shell instead of starting from simple rectangular room splitting.
* **Architectural Logic:** Exterior conditions such as daylight-facing facades, entrance position, noisy/street sides, view direction, and underground/earth-retained walls are considered during plan generation.
* **Plan Generation:** The system is being built around structured geometry, editable vector-based floor plans, and rule-based architectural reasoning before moving toward advanced AI-assisted generation.
* **Export Vision:** Future export goals include professional formats such as SVG, PDF, DXF, and DWG for architecture and CAD workflows.
* **Long-Term Goal:** To create a practical SaaS platform that helps architects and designers generate, evaluate, edit, and export meaningful residential floor plan concepts.
